# Onamea Path

Any path from the graph created using Identities and Ids can be displayed as follows.

**example**
Onamea⭐⭐🏁👍/$sub⚡️☀️💡/onamea:1#💡💡🌸⏰🎁⚡️

- / path seperator
- $ sub key
- \> referent
- : namespacing in item id
- \# additional fingerprint

The additional fingerprint is calculated from the hash of concatenating the complete fingerprints of all the paths. 

The strength of the combined fingerprints for the example can be calculated as follows. 
- Onamea⭐⭐🏁👍 = (6 + 4) x 5bit = 50bit
- sub⚡️☀️💡 = (3 + 3) x 5bit = 30bit
- #💡💡🌸⏰🎁⚡️ = 6 x 5bit = 30 bit
- --------------------------------------
- total = 110bit
